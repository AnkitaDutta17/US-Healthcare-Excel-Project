# 🏥 US Healthcare Data Analysis (Excel Project)

This project analyzes US healthcare data using Microsoft Excel to uncover insights related to patient demographics, disease distribution, billing patterns, and cost optimization strategies.


## 🎯 Project Objective

* Understand key drivers of healthcare costs
* Analyze disease-wise billing variations
* Identify demographic trends in patient distribution
* Optimize healthcare cost and resource allocation


## 📁 Dataset Overview

The dataset includes:

* Patient demographics (age group, gender)
* Medical conditions (e.g., cancer, diabetes, hypertension)
* Billing amounts
* Admission type
* Insurance providers
* Duration of hospital stay


## 🔍 Key Analysis Performed

### 1. Disease-Specific Cost Analysis

* Identified high-cost diseases like cancer and diabetes
* Compared billing across different conditions

### 2. Demographic Analysis

* Analyzed patient distribution by age and gender
* Evaluated impact of demographics on healthcare costs

### 3. Patient Price Optimization

* Admission type vs billing amount
* Insurance provider vs medical condition
* Duration of stay vs billing trends

### 4. Patient Distribution Analysis

* Identified high-volume diseases like hypertension and obesity
* Examined patterns across age groups and gender


## 💡 Key Insights

* Disease type is the primary driver of healthcare costs
* Cancer and diabetes contribute the most to total expenses
* Demographic impact on cost is minimal compared to disease type
* Longer hospital stays generally increase billing, but treatment complexity also matters
* Insurance provider effectiveness varies by medical condition


## ✅ Recommendations

* Shift to a disease-centric cost planning approach
* Optimize operations for short-term hospital stays
* Align insurance selection with medical conditions
* Focus on preventive care for high-volume diseases


### 🛠️ Tools Used

* Microsoft Excel (Pivot Tables, Data Analysis, Visualization)


### 📌 How to Use

* Open the Excel file to explore dashboards and pivot tables
* Review insights and recommendations for healthcare optimization
